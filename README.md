# CheckVDOSP

เว็บแอปพลิเคชันค้นหาและดาวน์โหลดวิดีโอจาก **Douyin (抖音)** และ **Bilibili (哔哩哔哩)** แบบไม่มีลายน้ำ พร้อมระบบค้นหาจากลิงก์สินค้า **Shopee**

## ฟีเจอร์หลัก
1. **ค้นหาวิดีโอด้วยภาษาไทยหรืออังกฤษ**: พิมพ์คำค้นหาภาษาไทยหรืออังกฤษ ระบบจะแปลงคำค้นหาและดึงคลิปจาก Douyin และ Bilibili ให้อัตโนมัติ
2. **ค้นหาจากลิงก์ Shopee**: วางลิงก์สินค้า Shopee (ทั้งลิงก์แบบเต็ม, ลิงก์หน้าเว็บ `/product/...` และลิงก์แบบย่อ `s.shopee.co.th`) ระบบจะดึงข้อมูลสินค้าและค้นหาวิดีโอที่เกี่ยวข้องให้ทันที
3. **ดูตัวอย่างคลิป & ดาวน์โหลด**: ดูพรีวิววิดีโอในหน้าเว็บ และดาวน์โหลดเป็นไฟล์ MP4 แบบไม่มีลายน้ำ หรือดาวน์โหลดเฉพาะเสียง MP3

## วิธีติดตั้งและรันใช้งาน

### 1. ติดตั้ง Dependencies
```bash
pip install -r requirements.txt
```

### 2. รันแอปพลิเคชัน
ดับเบิลคลิกไฟล์ `start.bat` หรือรันคำสั่ง:
```bash
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```
จากนั้นเปิดเบราว์เซอร์ไปที่:
```
http://localhost:8000
```
